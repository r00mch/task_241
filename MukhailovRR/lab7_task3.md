# 1. Что такое ssh ключи 
SSH-ключи — это пара криптографических ключей (публичный и приватный), используемая для:
Аутентификации без пароля (более безопасно)
Автоматизации подключений (скрипты, CI/CD)
Шифрования соединения между клиентом и сервером
Принцип работы:
Приватный ключ хранится только у вас на компьютере (никогда не передается)
Публичный ключ копируется на сервер
При подключении сервер проверяет, что у клиента есть соответствующий приватный ключ
# 2.Как создать SSH-ключи?
ssh-keygen -t ed25519
-t ed25519 — алгоритм шифрования

# 3.Где хранятся ключи?
## Показываем созданные ключи
ls -la ~/.ssh/
Расположение: ~/.ssh/ (директория .ssh в домашней папке пользователя)

# 4.Копирование публичного ключа на сервер
ssh-copy-id -p 231 student@ternar.io
Хранится в ~/.ssh/authorized_keys
