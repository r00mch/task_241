# 1.Что такое шебанг?
Шебанг (символы #!) — это первые два символа в текстовом файле скрипта, которые указывают системе, какая программа должна выполнить этот файл.
Это указание для загрузчика программ.
## Как работает: 
Когда вы запускаете файл с шебангом (например, ./script.sh), 
ядро Linux читает первую строку, находит указанный интерпретатор и запускает его, передавая файл скрипта в качестве аргумента.
# 2.Обязательно ли исполняемый файл должен иметь соответствующее расширение?
НЕТ, не обязательно. В Linux расширения файлов — это просто соглашение для удобства пользователей. 
Система определяет исполняемый файл по двум признакам:
1. Бит исполнения (x) — установлен ли право на выполнение 
2. Шебанг — для текстовых скриптов
