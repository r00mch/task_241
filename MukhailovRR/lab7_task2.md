# 1.Где хранятся пользовательские и системные настройки подключения?
Пользовательские настройки SSH-клиента:
~/.ssh/config. Применяются только для текущего пользователя.

Системные (глобальные) настройки SSH-клиента:
/etc/ssh/ssh_config. Применяются для всех пользователей по умолчанию.
# 2.Файл options
~/.ssh/config — специальный файл конфигурации SSH-клиента, в котором можно задавать параметры подключения к разным хостам
# 3. Редактирование файла options 
Нужно добавить в файл
bash
Host myserver
    Hostname ternar.io
    User student
    Port 231
