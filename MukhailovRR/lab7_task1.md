# 1.Какой по умолчанию используется порт для подключения?
Ответ: По умолчанию SSH использует порт 22
# 2.Можно ли его изменить? Если да, то как?
Ответ: Да, можно. Для изменения порта нужно:
## Отредактировать файл конфигурации SSH
sudo nano /etc/ssh/sshd_config
## Найти строку с Port и изменить значение
## Убрать комментарий (#) если он есть
Port 2222 
## Перезапустить службу SSH
sudo systemctl restart sshd
## Проверить, что служба слушает новый порт
sudo ss -tlnp | grep ssh
# 3.Какая служба отвечает за обработку запросов на подключения по SSH?
Ответ: Служба sshd (SSH Daemon)
# 4.Какой файл конфигурации отвечает за его настройку?
Ответ: Основной файл конфигурации - /etc/ssh/sshd_config
