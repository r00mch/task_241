# 1.Raid массивы, что такое икакие бывают

RAID (Redundant Array of Independent Disks) - технология объединения нескольких дисков в один логический элемент для повышения производительности и надежности.

Основные типы RAID:

RAID 0 (Stripe) - чередование:

Принцип: Данные разбиваются на блоки и пишутся на все диски одновременно

Плюсы: Максимальная производительность (скорость чтения/записи = сумма дисков)

Минусы: Нет отказоустойчивости - выход одного диска = потеря всех данных

Минимально дисков: 2

Эффективная емкость: сумма всех дисков

RAID 1 (Mirror) - зеркалирование:

Принцип: Одни и те же данные пишутся на все диски

Плюсы: Высокая надежность, отказоустойчивость

Минусы: Низкая эффективность использования места (50%)

Минимально дисков: 2

Эффективная емкость: размер одного диска

RAID 5 - чередование с контролем четности:

Принцип: Данные и контрольные суммы распределены по всем дискам

Плюсы: Отказоустойчивость + эффективное использование места

Минусы: Сложность восстановления, требуется минимум 3 диска

Минимально дисков: 3

Эффективная емкость: (n-1) * размер диска

RAID 6 - двойной контроль четности:

Принцип: Как RAID 5, но с двумя контрольными суммами

Плюсы: Выдерживает отказ 2 дисков

Минусы: Еще меньше эффективной емкости

Минимально дисков: 4

Эффективная емкость: (n-2) * размер диска

# 3.Создание RAID 0 массива

Установка mdamdm

sudo apt update

sudo apt install mdadm -y

## Создаем RAID 0

sudo mdadm --create /dev/md0 --level=0 --raid-devices=2 /dev/sdb1 /dev/sdc1

## Проверяем

cat /proc/mdstat

sudo mdadm --detail /dev/md0

## Создаем файловую систему

sudo mkfs.ext4 /dev/md0

## Монтируем

sudo mkdir /mnt/raid0

sudo mount /dev/md0 /mnt/raid0

## Проверяем

df -h /mnt/raid0

mount | grep raid0

# 4.Удаление RAID 0 и создание RAID 1

Удаление RAID 1

## Размонтируем

sudo umount /mnt/raid0

## Останавливаем RAID

sudo mdadm --stop /dev/md0

## Очищаем суперблоки

sudo mdadm --zero-superblock /dev/sdb1 /dev/sdc1

## Проверяем

# 5.Разница между RAID 1 и RAID 0

Ключевые отличия:

Цель: RAID 0 - для скорости, RAID 1 - для надежности

Безопасность данных: RAID 0 не защищает, RAID 1 защищает от выхода диска из строя

Объем доступного пространства: RAID 0 использует все пространство, RAID 1 - половину

Критичность отказа: RAID 0 - один сбой = потеря всех данных, RAID 1 - система работоспособна при сбое одного диска

Стоимость хранения: RAID 1 дороже в расчете на 1 ГБ полезного пространства

# 6. Есть ли файловые системы, которые поддерживают RAID массивы без стороннего ПО?

Да, есть:

Btrfs - имеет встроенную поддержку RAID 0, RAID 1, RAID 10, RAID 5, RAID 6. Создается командой mkfs.btrfs с параметрами -d (для данных) и -m (для метаданных).

ZFS - изначально включает поддержку RAID-Z (аналог RAID 5), RAID-Z2 (аналог RAID 6), зеркалирование и стрипы. Работает через пулы хранения.

Эти файловые системы реализуют RAID на уровне файловой системы, а не на уровне блочных устройств.

# 7.Можно ли создать RAID массив во время установки системы?

Да, можно:

При установке большинства дистрибутивов Linux (Ubuntu, Debian, CentOS, RHEL) в режиме ручного разбиения диска есть опция "Configure Software RAID" или "Создать RAID устройство". 

Позволяет создать RAID 0, 1, 5, 6, 10 до установки ОС, и система будет установлена на созданный RAID массив.
