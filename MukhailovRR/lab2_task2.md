# 1.Запретить пользователю user1 выполнять вход в систему
## Заблокировать аккаунт user1
sudo passwd -l user1
## Проверить статус
sudo passwd -S user1
## Вывод: user1 L 01/01/1970 0 99999 7 -1
## "L" означает Locked (заблокирован)

# Как вы это сделали?
## Я сделал это с помощью блокировки входа(пароля) для юзер1\
## Есть еще способы удаления пользователя: 
## Способ 1: Установить несуществующую оболочку
## Меняем оболочку на /usr/sbin/nologin
sudo usermod -s /usr/sbin/nologin user1
## Способ 2: Установить срок действия аккаунта в прошлое
## Устанавливаем дату истечения аккаунта
sudo chage -E 0 user1 
## Способ 3: Изменить домашнюю директорию
## Меняем домашнюю директорию на несуществующую
sudo usermod -d /nonexistent user1
## Способ 4: Удалить из всех групп (кроме primary)
## Оставляем только primary группу
sudo usermod -G "" user1
## Проверка
groups user1
## user1 : user1
## 4. Можно ли создать пользователей с одинаковыми username?
## Нет, нельзя. Система Linux не позволяет создать двух пользователей с одинаковым логином.
